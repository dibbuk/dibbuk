# dibbuk

Telegram-бот, который режет любую картинку, GIF или короткое видео
в готовый эмодзи-пак и тут же собирает из него картинку прямо в сообщении.

## Что умеет

- **Нарезка на тайлы 100×100** — сетка подбирается автоматически или задаётся вручную, от 1 до 12 колонок.
- **Анимация** — GIF и видео до 3 секунд кодируются в WEBM VP9 с альфа-каналом.
- **Поля** — сжимают или разрежают содержимое тайла. Решают главную боль ниши:
  картинку, которая «не сходится встык» на части клиентов.
- **Кадрирование** — «заполнить» обрезает края, «вписать» сохраняет картинку целиком.
- **Удаление фона** — заливкой от краёв, без тяжёлых нейросетевых зависимостей.
- **Мозаика в сообщении** — бот присылает картинку, собранную из кастомных эмодзи.
  Работает потому, что боты отправляют кастомные эмодзи без Telegram Premium.

## Монетизация

Модель выбрана по результатам [конкурентного анализа](docs/research/competitors.md) —
это единственная схема, которая в этой нише доказанно приносит деньги.

| Слой | Что даёт |
|---|---|
| Бесплатно | 5 паков в сутки, в названии пака стоит ссылка на бота |
| Разовая покупка за Stars | Снимает ссылку с одного пака |
| Подписка за Stars | Без лимитов, без ссылки, приоритет в очереди |

Ссылка в названии пака работает одновременно пейволлом и вирусной петлёй:
пак расходится по чатам и приводит новых пользователей.

## Запуск

Локально:

```bash
cp .env.example .env          # впишите BOT_TOKEN от @BotFather
pip install -e ".[dev]"
python -m bot.main
```

Через Docker, где ffmpeg уже внутри образа:

```bash
cp .env.example .env
docker compose up -d
```

**Развёртывание на сервере — [пошаговая инструкция](docs/deploy.md).**

Два условия, о которых стоит знать заранее:

- Для анимированных паков нужен **ffmpeg с libvpx-vp9**. Без него бот при старте
  сам отключит анимацию и продолжит работать со статикой.
- Для сборки картинки в сообщении Telegram требует **Premium у владельца бота**
  либо юзернейм, купленный на Fragment. На создание самих паков это не влияет:
  они работают в любом случае.

## Структура

| Путь | Назначение |
|---|---|
| `bot/slicing/grid.py` | Геометрия сетки. Чистая математика, все краевые случаи |
| `bot/slicing/static.py` | Нарезка картинок, паддинг, удаление фона |
| `bot/slicing/animated.py` | Нарезка анимации через ffmpeg, подгонка под лимит 256 КБ |
| `bot/mosaic.py` | Сборка картинки из эмодзи в тексте, смещения в UTF-16 |
| `bot/packs.py` | Создание пака через Bot API, правила именования |
| `bot/handlers.py` | Диалог: приём файла, панель настроек, нарезка, оплата |
| `bot/storage.py` | Состояние пользователя, квоты, подписка |
| `docs/research/competitors.md` | Конкурентный анализ ниши |
| `docs/deploy.md` | Пошаговое развёртывание на VPS |
| `deploy/dibbuk.service` | Юнит systemd |

## Ограничения платформы

Заданы Telegram и обойти их нельзя:

- Статика: PNG или WEBP, ровно 100×100 px.
- Анимация: WEBM VP9, 100×100 px, до 3 секунд, до 30 FPS, до 256 КБ на файл.
- До 200 эмодзи в одном паке.
- Имя пака обязано оканчиваться на `_by_<bot_username>`.
- Бот не может создать пак для пользователя, который не запускал этого бота.
- Создавать паки Premium не требует; отправлять кастомные эмодзи человеку — требует.
